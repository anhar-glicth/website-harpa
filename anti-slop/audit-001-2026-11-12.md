## Daftar Temuan Bernomor

### Group 1: Hard Gate (Priority: HIGH)

1. **[HIGH | R-17, R-18, R-36, R-38, C-5] Popup bukti sosial menampilkan daftar donatur fiktif hardcoded**
   - **Lokasi:** `laravel/resources/views/layouts/app.blade.php` (baris 763–794, 806–810)
   - **Alasan:** `liveDonationToast()` menyisipkan 7 nama dan nominal donasi fiktif (`Siti Rahmawati`, `Budi Santoso`, `Ahmad Fauzi`, `Nurul Hidayah`, `Dedi Kurniawan`, `Rina Permata`) beserta label `"Terverifikasi"` ke array publik `[...this.donations, ...this.fallback]` bahkan ketika data asli ada atau kosong.

2. **[HIGH | R-17, R-38] Statistik angka dampak di hero berfallback angka hardcoded**
   - **Lokasi:** `laravel/resources/views/home.blade.php` (baris 123, 136, 149)
   - **Alasan:** Kartu *Penerima Manfaat*, *Project Kebaikan*, dan *Perwakilan Relawan* menampilkan angka default hardcoded `'2.500 +'`, `'95 +'`, `'20 +'` bila `$settings` kosong, bukan angka nyata dari database atau label placeholder eksplisit.

3. **[HIGH | R-25] Kontras tombol `bg-emerald-600 text-white` gagal WCAG AA (`3.81:1 < 4.5:1`)**
   - **Lokasi:** `laravel/tailwind.config.js` (baris 47–59), `laravel/resources/views/layouts/app.blade.php` (baris 64–76), `laravel/resources/views/admin/sidebar.blade.php`, dan views `laravel/resources/views/admin/harpa/*.blade.php` (`daftar_kirim.blade.php`, `import_donasi.blade.php`, `blast_history.blade.php`, `wbs_pro.blade.php`, `papan_kerja.blade.php`)
   - **Alasan:** Skala `emerald` di-override menjadi kuning/emas (`#b97307` untuk `600`, `#df9408` untuk `amber-600`); uji `contrast-check.py` menghasilkan `#FFFFFF` di atas `#b97307` = `3.81:1` (FAIL normal text) dan `#df9408` di atas `#FFFFFF` = `2.51:1` (FAIL).

4. **[HIGH | R-25] Kontras `text-slate-400` (`#94a3b8`) gagal WCAG AA di atas latar putih, slate-50, dan Navy**
   - **Lokasi:** `laravel/resources/views/layouts/app.blade.php` (baris 627, 748, 757, 861, 902, 977), `home.blade.php` (baris 165, 214, 265, 285, 407, 424, 452, 478), `campaigns/index.blade.php` (baris 10, 24, 31, 84), `campaigns/show.blade.php` (baris 15, 46, 58, 70, 102, 107), `donations/checkout.blade.php` (baris 7, 17, 23, 27, 37), dan views `admin/harpa/*.blade.php`
   - **Alasan:** Uji `contrast-check.py` membuktikan `#94a3b8` di atas `#FFFFFF` = `2.56:1` (FAIL), di atas `#F8FAFC` = `2.45:1` (FAIL), dan di atas `#063f5c` footer = `4.37:1` (FAIL < `4.5:1`).

5. **[HIGH | R-25] Kontras teks `text-primary-500` di atas latar gelap `bg-slate-900` gagal WCAG AA (`2.25:1`)**
   - **Lokasi:** `laravel/resources/views/auth/login.blade.php` (baris 5, 42) dan `layouts/guest.blade.php`
   - **Alasan:** Uji `contrast-check.py` untuk `#0e567d` di atas `#0f172a` menghasilkan `2.25:1` (FAIL normal dan large text) pada subjudul "Datang Kembali" dan tautan "Lupa Sandi?".

6. **[HIGH | R-24, R-26] Tautan media sosial mati (`href="#"`) di footer utama**
   - **Lokasi:** `laravel/resources/views/layouts/app.blade.php` (baris 548–550)
   - **Alasan:** Tautan Instagram, Facebook, dan YouTube mengarah ke `href="#"` sehingga tidak melakukan navigasi apa pun saat diklik.

7. **[HIGH | R-32, R-39] Header grup menu sidebar menggunakan `<div @click>` tanpa dukungan keyboard atau ARIA**
   - **Lokasi:** `laravel/resources/views/admin/sidebar.blade.php` (baris 52, 107, 151, 316, 348, 432, 467) dan `laravel/resources/views/components/dropdown.blade.php` (baris 17)
   - **Alasan:** Elemen interaktif berupa `<div>` klik alih-alih `<button type="button" :aria-expanded="isOpen">`, sehingga pengguna keyboard (`Tab`/`Enter`/`Space`) dan pembaca layar tidak dapat membuka grup navigasi admin.

8. **[HIGH | R-32, R-26, R-39] Modal custom tidak bisa ditutup dengan tombol `Escape` dan tombol tutup ikon kurang `aria-label`**
   - **Lokasi:** `laravel/resources/views/layouts/app.blade.php` (baris 851–981 modal Login/Register), `admin/harpa/blast_history.blade.php` (baris 162, 290), `admin/harpa/wbs_pro.blade.php` (baris 144, 244), `admin/distributions.blade.php`, `admin/programs.blade.php`, serta template modal admin lainnya
   - **Alasan:** Hanya `<x-modal>` yang punya `keydown.escape`; modal custom tidak merespons tombol `Escape` serta memakai tombol `fa-xmark` tanpa `aria-label="Tutup"` dan tanpa `aria-hidden="true"` pada ikon.

9. **[HIGH | R-32, R-39] Pemakaian massal `outline-none` (468 titik) tanpa indikator `:focus-visible` dan hilangnya base-layer `cursor: pointer`**
   - **Lokasi:** `laravel/resources/views/layouts/app.blade.php` (baris 111–139), `layouts/guest.blade.php`, serta 468 kemunculan `outline-none` di views Blade
   - **Alasan:** Base CSS tidak menetapkan aturan `:focus-visible` berketebalan/kontras `>= 3:1` sebagai pengganti `outline-none`, dan tidak menetapkan `cursor: pointer` pada `button`, `select`, `summary`, dan `label[for]` (tertimpa Tailwind preflight).

10. **[HIGH | R-39, R-40] Slider hero berjalan otomatis > 5 detik tanpa tombol jeda, tanpa HTML `<img>` ber-`fetchpriority="high"`, dan gambar tanpa dimensi eksplisit**
    - **Lokasi:** `laravel/resources/views/home.blade.php` (baris 5–109, 48–52, 177–181, 463–467), `campaigns/index.blade.php` (baris 47–51), `campaigns/show.blade.php` (baris 24–28, 50)
    - **Alasan:** Carousel otomatis berpindah setiap 4 detik tanpa kontrol jeda untuk pengguna; slide hero dirender via JS Alpine tanpa elemen `<img>` utama ber-`fetchpriority="high"`; serta gambar-gambar belum mencantumkan atribut `width`/`height` eksplisit (serta `alt=""` dekoratif belum dibedakan).

11. **[HIGH | R-40] Skrip `cdn.tailwindcss.com` dimuat sinkron (render-blocking) di `<head>`**
    - **Lokasi:** `laravel/resources/views/layouts/app.blade.php` (baris 23) dan `laravel/resources/views/layouts/guest.blade.php`
    - **Alasan:** Memuat parser JS Tailwind CDN secara sinkron di `<head>` menahan render pertama halaman di perangkat seluler, tidak dikompilasi via Vite CSS build.

12. **[HIGH | R-39] Label formulir tanpa `for`/`id` yang terhubung serta class CSS fiktif (`slate-450`, `slate-150`, `slate-350`)**
    - **Lokasi:** `laravel/resources/views/donations/checkout.blade.php` (baris 17, 23, 27, 37), `prayers/index.blade.php` (baris 85, 100–101), `layouts/app.blade.php` (baris 874–965)
    - **Alasan:** Label form di `checkout.blade.php` dan `prayers/index.blade.php` tidak memiliki atribut `for` menuju `id` input; selain itu class `text-slate-450`, `border-slate-150`, dan `text-slate-350` tidak ada di konfigurasi Tailwind sehingga border dan warna teks tidak terbentuk.

13. **[HIGH | R-03] Bug layout mobile `col-span-3` di `grid-cols-2` dan target sentuh tombol ikon `< 44px`**
    - **Lokasi:** `laravel/resources/views/campaigns/index.blade.php` (baris 97) dan `laravel/resources/views/layouts/app.blade.php` (baris 257, 634–702, 771)
    - **Alasan:** Kondisi `@empty` pada daftar kampanye memakai `col-span-3` di dalam `grid-cols-2 lg:grid-cols-3`, yang membuat kolom ke-3 paksa dan memicu geser horizontal di ponsel; beberapa tombol ikon (tutup toast, aksi tabel) juga lebih kecil dari `44x44px`.

14. **[HIGH | R-02] Penggunaan karakter em dash (`—`) pada opsi dropdown dan sel antarmuka**
    - **Lokasi:** `laravel/resources/views/admin/programs.blade.php` (baris 164, 249, 315), `admin/payment_via.blade.php` (baris 150, 159), `admin/program_groups.blade.php` (baris 145), `admin/targets.blade.php` (baris 157, 163), `admin/attendance.blade.php` (baris 45, 52, 59, 66), `admin/dashboard.blade.php` (baris 51, 58, 65, 72)
    - **Alasan:** Teks antarmuka mengandung karakter em dash (`—`), termasuk di placeholder dropdown (`— Pilih Rumpun Program —`), melanggar larangan karakter em dash (R-02).

15. **[HIGH | R-33] Skrip patch pengubah kode sumber (`fix_admin.ps1`) berada di repositori**
    - **Lokasi:** `fix_admin.ps1` (baris 1–8)
    - **Alasan:** Tersedia skrip PowerShell pengubah teks sumber via string replace di root proyek.

16. **[HIGH | R-27, R-39] Halaman `daftar_kirim.blade.php` belum memiliki indikator teks loading saat sinkronisasi AJAX dan halaman autentikasi (`guest.blade.php` + `login.blade.php`) tanpa `<main>` serta `<h1>`**
    - **Lokasi:** `laravel/resources/views/admin/harpa/daftar_kirim.blade.php` (baris 252–290), `laravel/resources/views/layouts/guest.blade.php`, `laravel/resources/views/auth/login.blade.php` (baris 4), serta `layouts/app.blade.php` (aturan `prefers-reduced-motion: reduce`)
    - **Alasan:** Saat update massal berjalan di `daftar_kirim.blade.php`, pengguna belum melihat indikator teks/spinner status pemuatan yang eksplisit; halaman auth tidak memiliki landmark `<main>` dan heading `<h1>`, dan layout belum membungkus transisi dengan `prefers-reduced-motion: reduce`.
